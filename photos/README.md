# Папка с фотографиями

Сюда кладутся все фотографии сайта.

## Фото в блоке «О нас»

- Фото: `about.png` — Елена и Екатерина, показано в рамке блока «О нас»
  (строка с `<img src="photos/about.png">` в `index.html`).
- Как заменить фото: положите новое изображение в эту папку с именем `about.png`
  и проверьте путь в `index.html`.
- Фото обрезается под пропорцию 4:5 (`object-fit: cover`),
  поэтому хорошо подходят портретные кадры.

## Фото работ (галерея)

- Файлы: `work-01.jpg` … `work-22.jpg` — фото работ в галерее.

**Важно:** сайт статический, поэтому новые фото НЕ подхватываются автоматически.
Чтобы фото появилось в галерее, нужно добавить его имя в `js/main.js`
в массив `GALLERY` — одна строка на фото:

```js
const GALLERY = [
    "photos/work-01.jpg",
    "photos/work-02.jpg",
    ...
    "photos/work-23.jpg"   // ← новое фото
];
```

Как это работает:
- В сетке показываются первые 6 фото.
- Если фото больше 6, под галереей появляется стрелочка:
  по нажатию ниже раскрываются все остальные фото,
  повторное нажатие сворачивает галерею обратно.
- Клик по любому фото открывает его в полном размере
  (листаются стрелками, закрывается по Esc).
- Порядок в массиве = порядок в галерее.
- Новое фото лучше сразу называть по шаблону `work-NN.jpg`,
  чтобы список оставался аккуратным.
